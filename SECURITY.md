# Security Policy

Maintained by **SamAlpha1**.

## Reporting a vulnerability

Do not publish private keys, seed phrases, access tokens, passwords, or exploit details in public issues. Open a minimal issue without sensitive data and request a private contact path.

## Security principles

- Never commit secrets or API credentials.
- Keep `.env` and local credential files out of Git.
- Review dependencies and workflow changes before merging.
- Treat price-feed endpoints and notification credentials as security-sensitive.
